Any script names containing the phrase "_vis" will require pygame-ce.
If it is not stated with "_vis" after, assume it is a terminal based game.

On Minesweeper_Vis, you can push 1, 2, 3, 4, and 5 to increase the difficulty. (Size and mine count increases)
"R" to reset, "/" if you're struggling.
Any mouse input counts a tile dig, so the spacebar is the flag, no "?" states.
You will also need to install numpy for the "random" feature of this build.

Minesweeper, the non "_Vis", is a little harder to control and understand, but shines by the fact it's in the terminal.
IT DOES NOT HAVE THE SELF CLEAR FEATURE YET, YOUR TERMINAL WILL BE FLOODED.
You have been warned. (Just close and open the terminal again to spare some sanity)
